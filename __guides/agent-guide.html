🗺️ SDLC — End-to-End Flow

Three views of the same process: the full sprint journey from gap to live, the daily session rhythm, and how tech debt flows through the system. HITL gates are shown where human approval is mandatory.
1
Backlog
Gap Identification
Gap added to .agents/ROADMAP.md with a GAP-NN ID. If an architectural decision is required, /write-adr must be accepted before the sprint can be marked READY. Check the register and next sprint blockers with /sprint-status.
/sprint-status /write-adr
2
Plan
C
Sprint Planning
Optionally run /user-story-map first to capture WHO needs this and WHY (Jeff Patton + Toyota Kata framing) before planning HOW. Run pre-mortem to surface failure modes. Vet any new library dependencies. Build the sprint task card — no implementation code is written at this stage. HITL approves the task card before the first RED commit.
/user-story-map GAP-NN /pre-mortem /vet-library /build-sprint GAP-NN
🔴 HITL — confirm task card before first commit
3
Build
H
Sprint Execution — TDD Cycles
Agent executes freely within a task. Each feature follows RED → GREEN → REFACTOR. /sniff-test after every GREEN. Structural changes (renames, extractions) go through /tidy-first in separate commits before behaviour changes.
/run-sprint GAP-NN /tdd /sniff-test /tidy-first
🟡 SOFT HITL — "Continue? [y/n]" on each task boundary
4
Gate
G
Quality Gates — all 7 must pass
1 · gitleaks 2 · bandit 3 · ruff 4 · mypy 5 · pytest ≥80% 6 · CHANGELOG 7 · manual review
Failures block progression. Issues are either fixed immediately or raised as TD items (auto-refreshes the guide snapshot). Human approval required — agent cannot self-sign-off.
/quality-gates /roast /code-review /tech-debt raise
🔴 HITL — human approval required before close ⚡ AUTO — TD raise refreshes guide
5
Close
G
Sprint Close — 11 Steps
DoD audit → update SPRINT_REGISTER → write CHANGELOG entry (4-check validation) → close resolved TDs → raise deferred TDs → apply pending lessons → agent-guide.html snapshot refreshed automatically → HITL confirmation → git push origin vnext.
/sprint-close sprint-N
🔴 HITL — push requires explicit approval ⚡ AUTO — guide snapshot refreshed in commit
6
Live
CI/CD Pipeline → Production
Azure Pipelines orchestrates: Build_And_Test → Deploy_Dev → Bootstrap_Dev → Smoke_Test → Deploy_UAT → (manual approval gate) → Deploy_Prod. Fabric notebooks published via fab workspace publish. DirectLake Power BI refreshes via semantic model.
azure-pipelines.yml fab workspace publish 00-deploy.ps1
The sprint is the authoritative unit of work. The daily cycle is a scheduling view — tasks are picked from the active sprint plan, not chosen ad-hoc.
🌅 Session Start
Read the most recent handoff note for context. Run /day-plan — reads sprint register, open TDs, branch state, and inbox. Reviews any loose inbox files (HITL before moving).
/chat-handoff last /day-plan
🔴 HITL — review plan + inbox moves
⚙️ Execute Tasks
Pick next ⬜ TODO from day plan (or use /run-day-plan to auto-select and execute). Complete the task. Plan auto-ticked with commit SHA. Repeat. Run /token-budget after 10+ tool calls.
/run-day-plan /token-budget
🟡 SOFT HITL — "Continue? [y/n]"
🔍 Light Review
Run /sniff-test on changed files. Convert any new lessons to guardrails with /lessons-to-guardrails — raises TD items for deferred work (auto-refreshes guide). Save the full 7-gate run for sprint close.
/sniff-test /lessons-to-guardrails
⚡ AUTO — TD raise refreshes guide
🌙 Session End
Run /chat-handoff — generates handoff note, committed with [skip ci]. If all sprint tasks are done, prompt for /sprint-close. Push always requires explicit HITL approval.
/chat-handoff /sprint-close
🔴 HITL — push always requires approval

🎯 Vibe Modes

CREATION C
Planning and scaffolding only. No implementation code. Produces: task cards, ADRs, migration SQL, pre-mortem output. Agent may ask freely. No HITL for file writes.
/build-sprint /write-adr /pre-mortem /vet-library /day-plan
HARDENING H
Active implementation. RED→GREEN→REFACTOR cycles. Agent executes freely within a task. HITL required before crossing task boundaries, writing to shared state, or pushing.
/run-sprint /tdd /tidy-first /sniff-test /lessons-to-guardrails
GATEKEEPER G
Verification and audit only. No new code. Produces pass/fail verdicts. All gate failures block until resolved. Human approval required before sprint can be COMPLETE.
/quality-gates /sprint-close /roast /code-review /token-budget

⚡ Auto-Triggered Commands

These three workflows fire when you say a natural language phrase — no slash command needed. All other workflows require explicit slash command invocation.
/chat-handoff ⚡ AUTO
Generates a self-contained handoff note and commits it to .agents/handoffs/. Use at end of session or to seed a new one.
chat handoff chat handover handoff note new session start fresh reset session
/lessons-to-guardrails ⚡ AUTO
Converts retrospective lessons in .agents/LESSONS.md into structural guardrails (code, templates, checklists, or deferred TD items).
lessons to guardrails tidy pass apply lessons tidy first lessons learned guardrail
/token-budget ⚡ AUTO
Audits and reduces AI context/token usage. Run before a new sprint, after 10+ tool calls, or when the agent starts losing track of earlier decisions.
session getting expensive context audit compact before sprint token budget context window reduce tokens

If the current sprint is READY (not yet started), flags whether a story map exists for the gap and recommends /user-story-map if not. Outputs a structured markdown plan with YAML frontmatter.

🚦 7-Gate Quality Model

All 7 gates must pass before merge. Record py -m pytest tests/ -q --tb=no baseline before any edit.
1Secret Scan
gitleaks detect --verbose
No secrets in any tracked file.
2Security Lint
bandit -r src/ -ll -f text
No HIGH/MEDIUM. LOW with justification.
3Ruff
ruff check src/ tests/ scripts/ --select=E,W,B,S,C90 --ignore=S101,S603,S607
Zero violations. See user memory for noqa rules.
4mypy
mypy src/notebooks/ --ignore-missing-imports --no-strict-optional
No type errors. # type: ignore[name-defined] for Fabric-only symbols.
5pytest
pytest tests/ --cov=src/notebooks --cov-report=term-missing --cov-fail-under=80 -v
≥80% coverage. 1375 passing, 7 skipped (vnext baseline).
6CHANGELOG
cat CHANGELOG.md | head -40
Entry for every merged sprint.
7Manual Review
/code-review or /roast
Human approval required. No AI self-sign-off.

🚧 HITL Gates

Agent executes freely within a task. HITL is required at these boundaries.
🔴
Sprint open / closeHARD

Agent cannot mark READY→IN PROGRESS or IN PROGRESS→COMPLETE without explicit confirmation. /sprint-close is the gate.

🔴
git push / git push --forceHARD

Never push without asking. [skip ci] commits still require human approval before push.

🔴
Inbox file movesHARD

Agent surfaces inbox items but never moves or deletes without explicit per-item confirmation (or bulk [all-ref]).

🟡
Design confirm before first RED commitSOFT

In /tdd and /run-sprint: agent presents test design + function signature. User approves before writing the failing test.

🟡
Crossing task boundarySOFT

After completing a task, agent asks "Continue with Y? [y/n]" before proceeding.

🟡
Writing to shared stateSOFT

SPRINT_REGISTER.md, TECH_DEBT.md, CHANGELOG.md, .agents/handoffs/ — agent asks before any write that is not a draft.

🟡
DDL / column renamesSOFTSTOP-AND-THINK

Agent writes Live DEV migration SQL first. No code changes until SQL is approved.

🟢
File edits within changesetFREE

No HITL required for edits to files already in scope for the current task.

📐 Key Conventions

Import guards
REQUIRED
Every notebook must wrap Fabric/PySpark imports to keep 1375 pytest tests passing locally.
try: import sempy_labs from pyspark.sql import SparkSession except ImportError: sempy_labs = None
SQL injection guard
SECURITY
Required everywhere SQL is constructed with user/config data.
# Strings value.replace(chr(39), chr(39)*2) # IDs int(some_id)
Bronze audit columns
REQUIRED
Every Bronze table must include all three audit columns.
_AUDIT_COLS = ( "_ingested_at", "_source_system", "_pipeline_id" )
Gold V-Order
MANDATORY
DirectLake Power BI has no import cache fallback. Never disable V-Order in Gold.
spark.conf.set( "spark.sql.parquet.vorder.enabled", "true" )
No hardcoded names
REQUIRED
Lakehouse names, workspace IDs, environment strings are always parameters. Driven by Control DB at runtime.
# ❌ WRONG df.write.saveAsTable("lh_bronze.my_table") # ✅ RIGHT df.write.saveAsTable(f"{lakehouse}.{table}")
Python interpreter
Use full path. py.exe may resolve to wrong version.
C:\Users\scottm\AppData\Local\Programs\ Python\Python311\python.exe -m pytest
