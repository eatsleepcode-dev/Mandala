# Lessons Registry

Central log of retrospective lessons. Each lesson must include `Guardrail-type` and `Status`.

Full guide: [`docs/lessons-to-guardrails.md`](../docs/lessons-to-guardrails.md)

---

## Format

```markdown
## L-NNN: Short title describing the problem
**Sprint**: NNN | **Context**: where/when this happened
**Lesson**: What we learned — the insight, not just the symptom.
**Guardrail-type**: [A — Code | B — Template | C — Checklist | D — Knowledge-only]
**Guardrail**: Specific file, function, template, or step that changes.
              For Type D: N/A
**Status**: [⬜ PENDING | ✅ APPLIED: <commit SHA or PR link> | 📋 TD-NNN]
**Action**: What to do (or what was done).
```
